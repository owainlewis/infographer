What Is The AI Stack?

The AI engineering stack is the complete set of tools, patterns, and infrastructure needed to go from prototype to production. It's not just about picking a model — it's about building the full system around it.

Key Principles
  • Models are commoditising — the value is in your data and orchestration
  • RAG before fine-tuning — cheaper, faster, easier to update
  • Start with APIs, self-host later — don't over-engineer day one
  • Evaluation is everything — if you can't measure it, you can't improve it

Foundation Models
The Base Layer

Choose between API-hosted models (GPT-4o, Claude, Gemini) for speed, or open-weight models (Llama 3, Mistral, Qwen) for control. Key trade-offs:

  • Context window — how much data fits in one call
  • Reasoning depth — complex multi-step problems
  • Latency — time to first token matters for UX
  • Cost per token — scales with usage volume
  • Fine-tunability — can you adapt it to your domain?
  • Multimodal — text, image, audio, video support

Vector Databases
Semantic Memory

Store embeddings — numerical representations of text, images, or code — for fast semantic search. The backbone of RAG and agent memory.

Pinecone
Managed. Fast. Best for zero-ops teams.
Weaviate
Open source. Hybrid search. GraphQL.
pgvector
Postgres extension. Use what you have.
Chroma
Lightweight. Great for prototyping.
Qdrant
Rust-based. High performance filtering.
Milvus
Scalable. Built for billion-scale data.

Start simple: pgvector if you're on Postgres. Move to a dedicated vector DB when you need scale.

Orchestration
The Glue Layer

Connects models to tools, APIs, and data sources. Manages chains, retries, fallbacks, and structured output.

  • LangChain — largest ecosystem, most batteries
  • LlamaIndex — data-first, great for RAG
  • PydanticAI — type-safe, Pythonic, async
  • Semantic Kernel — Microsoft's enterprise play
RAG Pattern
Grounded Answers

Retrieval-Augmented Generation — give the model your data at query time so it doesn't hallucinate.

  • Chunk documents into passages
  • Embed chunks as vectors
  • Store in a vector database
  • Retrieve relevant chunks at query time
  • Generate answer grounded in context
AI Agents
Autonomous Work

Agents plan, act, and iterate autonomously. They use tools, maintain state, and complete multi-step tasks without human guidance.

  • Claude Code — writes, tests, deploys code
  • CrewAI — multi-agent team workflows
  • AutoGen — Microsoft's agent framework

Fine-Tuning
Domain Adaptation

When prompting hits its limits. Adapt a model to your specific domain, style, or task.

  • LoRA / QLoRA for efficient training
  • Small datasets (100–10K examples)
  • Best for style, format, domain language
  • Don't fine-tune for facts — use RAG instead
Inference & Deploy
Ship It

Get your model into production. Choose between managed APIs and self-hosted inference.

  • vLLM — fast open-source inference server
  • Ollama — run models locally, one command
  • Cloud APIs — pay per token, zero ops
  • GPU providers — Modal, Replicate, RunPod
