Inside Kubernetes

Cluster Architecture

The control plane schedules workloads and responds to cluster events. Worker nodes run your containerized applications as pods.

Core Concept
Pods

The smallest deployable unit. Wraps one or more containers sharing network and storage. Ephemeral by design.

Ephemeral Shared Network
Networking
Services

A stable endpoint that routes traffic to pods. Abstracts away pod IPs which change on every restart.
