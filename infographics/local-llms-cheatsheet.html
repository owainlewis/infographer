The Toolkit
Ollama
CLI-first. Pull and run models in one command. OpenAI-compatible API built in. The default choice for developers.
ollama run llama3.3
LM Studio
GUI app with model browser, chat UI, and local server. Great for exploring models without touching the terminal.
llama.cpp
The engine underneath. Pure C/C++ inference. Ollama and LM Studio both build on this. Use directly for max performance tuning.

Quick Start with Ollama
Step 1
Install Ollama

macOS: brew install ollama — Linux: curl script — Windows: installer from ollama.com

Step 2
Pull a model

ollama pull llama3.3 — downloads the quantized model (~4GB for 7B)

Step 3
Chat or serve

ollama run llama3.3 for chat — or ollama serve to expose the API on :11434

Step 4
Connect your tools

Point any OpenAI SDK at localhost:11434/v1 — works with LangChain, Continue, Cursor, etc.

Hardware Reality Check

RAM is the bottleneck. Models load entirely into memory. Quantization (Q4, Q5) shrinks them 4–8x with minimal quality loss.

  • 8GB RAM — 7B models (Mistral, Qwen 2.5 7B, Phi-4 mini)
  • 16GB RAM — 13–14B models (Phi-4, Qwen 2.5 14B)
  • 32GB RAM — 30–34B models (DeepSeek-R1 distilled)
  • 64GB+ RAM — 70B models (Llama 3.3 quantized)
Pro Tip

Apple Silicon excels at local LLMs — unified memory means the GPU can access all your RAM. A MacBook with 32GB runs 30B+ models at usable speed with no discrete GPU needed.
