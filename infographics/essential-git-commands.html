How to Master Git in 15 Minutes

01
git add

Stage changes for your next commit. Use -p to stage individual hunks — commit only what matters.

git add -p src/
Core -p for precision
02
git commit

Save a snapshot of staged changes. Each commit is permanent history. Write meaningful messages — your future self will thank you.

git commit -m "fix: auth redirect"
Core --amend to fix last
03
git branch

Create isolated lines of development. Branches are cheap pointers to commits. Use them for features, fixes, and experiments.

git switch -c feature/auth
Branching switch > checkout
04
git merge

Combine two branches together. Creates a merge commit that preserves both histories. The standard way to integrate changes.

git merge feature/auth
Integration --no-ff for clarity
05
git rebase

Replay commits onto a new base. Creates linear history by moving your branch to the tip of main. Squash, reorder, and edit.

git rebase -i main
Clean history -i for interactive
06
git stash

Shelve uncommitted work. Save changes to switch branches cleanly, then reapply later. A clipboard for your working directory.

git stash push -m "wip: sidebar"
Save WIP pop to restore
07
git cherry-pick

Apply a specific commit to your branch. Grab exactly the changes you need without merging everything. Essential for hotfixes.

git cherry-pick a1b2c3d
Surgical Hotfixes
08
git reset

Undo commits or unstage files. --soft keeps staged. --mixed unstages. --hard discards everything.

git reset --soft HEAD~1
Undo --hard is destructive
09
git reflog

Your safety net. Records every HEAD movement — even after reset, rebase, or deleted branches. Lost a commit? Reflog knows where it went.

git reflog show --date=relative
Recovery Undo anything
