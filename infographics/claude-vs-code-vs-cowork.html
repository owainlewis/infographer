Claude Code

A CLI tool that runs Claude as an autonomous coding agent directly in your terminal.

Where to use

  • Refactor legacy codebases at scale autonomously
  • Write and run tests, fixing failures automatically
  • Git workflows, PR reviews, and CI/CD tasks
