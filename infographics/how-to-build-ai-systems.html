How to Build AI Systems

01
Evals

A test suite that measures whether your AI produces good outputs. Without evals every change is a guess — you can't know if a new model or prompt made things better or worse.

Start with 20-50 hand-written test cases. Use LLM-as-Judge to score at scale. Expand based on real production failures.

Braintrust RAGAS LLM-as-Judge Golden Datasets
02
RAG & Retrieval

Retrieve relevant context from your data and inject it before generation. 90% of RAG failures are retrieval failures, not generation failures.

Chunk, embed into vectors, retrieve by hybrid search (semantic + keyword), rerank top results, then generate. Fix retrieval before tuning anything else.

pgvector PydanticAI Hybrid Search Reranking
03
Models & Routing

Dynamically select which model handles each request. A simple task routed to a cheap model costs 100x less than the same task on a frontier model.

Classify by complexity. Route simple tasks to fast cheap models, complex reasoning to frontier models. Implement fallback chains for resilience.

Bedrock Vertex AI LiteLLM Fallback Chains
04
Observability & Tracing

Full visibility into every LLM call, tool invocation, and decision point. A 200 OK can still be a hallucinated answer — without tracing you're debugging by guessing.

Instrument every call with Langfuse. Track token costs per feature, latency at p95, and quality drift. Add this on day one — retrofitting is 5x harder.

Langfuse Agent Traces Token Costs TTFT
05
Guardrails & Security

Validation layers that check inputs and outputs against safety and business rules. Prompt injection is OWASP's #1 LLM vulnerability and only 34% of teams defend against it.

Validate inputs for injection, outputs for PII leakage and harmful content. Apply least-privilege to agents with tools. Design for blast radius reduction.
