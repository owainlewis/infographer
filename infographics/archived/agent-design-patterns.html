7 AI Agent Design Patterns

01 · FOUNDATION Augmented LLM

An LLM enhanced with retrieval, tools, and memory. This is the base unit — every other pattern is built from this.

The building block for all agents

02 Prompt Chaining

Break a task into sequential steps. Each call processes the previous output. Add gates to check quality.

03 Routing

Classify the input, then dispatch to specialized handlers with optimized prompts.

04 Parallelization

Sectioning (split into parallel subtasks) or voting (same task N times). Speed or confidence.

05 Orchestrator-Workers

A central LLM dynamically decides subtasks, delegates to workers, synthesizes results.

06 Evaluator-Optimizer

One LLM generates, another evaluates and gives feedback. Loop until quality criteria met.

Reject → retry → converge on quality

07 · AUTONOMOUS Autonomous Agent

The LLM dynamically directs its own process — choosing tools, planning steps, and reacting to feedback in a loop. Most flexible, hardest to control.

Only use when you can't predict the steps needed

Needs guardrails — hardest pattern to control and debug.
