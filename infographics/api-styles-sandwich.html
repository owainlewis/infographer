01

RESTful

Uses standard HTTP methods. Statelessness, cacheability, and a uniform interface are key constraints.

Best for → Public APIs, CRUD apps, mobile backends, broad client compatibility.

HTTP verbs Stateless Cacheable Resource-based
02

GraphQL

Clients request only the data they need. Eliminates over-fetching and under-fetching entirely.

Best for → Complex frontends, mobile apps with bandwidth constraints, data aggregation.

Query language Single endpoint Typed schema
03

SOAP

Protocol-based standard using XML with built-in security, transactions, and ACID compliance.

Best for → Banking, payment processing, enterprise integrations requiring strict contracts.

XML-based WS-Security WSDL contract

WebSockets

Real-time, full-duplex communication over a single persistent TCP connection.

Best for → Chat, live dashboards, multiplayer games, collaborative editors.

Lightweight messaging using publish-subscribe. Designed for constrained networks and IoT devices.

Best for → IoT devices, sensor networks, smart home, low-bandwidth environments.
