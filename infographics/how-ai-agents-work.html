How AI Agents Work

The Agent Loop — a while loop around a text predictor
01
The Prompt

Every call re-sends the entire conversation from scratch. System prompt, message history, tool results — all of it. There is no persistent thread.

Stateless Re-sent every time
02
Tools

The AI can only type. It outputs structured JSON — function name + args. Your code actually runs it and feeds the result back. The AI is the manager, your code is the worker.

Your code runs it JSON in/out
03
Context Window

Everything the model knows must fit in a fixed token budget. System prompt + history + tools + response. Overflow it and it silently forgets the beginning.

The bottleneck 128K–1M tokens
04
Planning

Without a plan, agents hallucinate or loop. Good agents write steps before acting. This "chain of thought" forces the model to verify its own logic before using tools.

Think first Self-prompting
05
Memory

Agents don't "remember." When a conversation ends, your code saves it to a database. Next time, it searches that archive and pastes relevant bits into the new prompt.

Save → search → inject External storage
06
Guardrails

The AI has no common sense. Give it a delete tool and it might delete everything. You must write hard constraints — your code rejects dangerous calls before they run.
