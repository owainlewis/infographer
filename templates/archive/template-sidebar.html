Docker Commands Cheat Sheet

Categories
Build
Images, Dockerfiles, layers
Run
Containers, ports, volumes
Network
Bridges, DNS, port mapping
Debug
Logs, exec, inspect, stats
Compose
Multi-container orchestration
Clean Up
Prune images and volumes
Build
docker build -t app:v1 . Build from current Dockerfile
docker build --no-cache . Build without layer cache
docker images List all local images
Run
docker run -d -p 8080:80 app Run detached with port mapping
docker run -it --rm app sh Interactive shell, auto-remove
docker ps -a List all containers
Network & Debug
docker network create mynet Create bridge network
docker network inspect mynet Show network config
docker port <id> List port mappings
docker logs -f <id> Stream logs in real time
docker exec -it <id> sh Shell into running container
docker stats Live CPU, memory, I/O
Clean Up
docker system prune -a Remove all unused resources
docker volume prune Remove unused volumes
Compose
docker compose up -d Start all services
docker compose down -v Stop and remove everything
