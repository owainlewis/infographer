What Is Agentic AI?

The 5 layers that turn a chatbot into an autonomous agent.

01 Foundation Models The brain
  • LLMs like GPT-4, Claude, Gemini
  • Trained on vast datasets of text and code
  • Reasoning and language understanding
  • Generate plans, not just completions
  • Can process images, audio, and video
  • Context windows up to 1M+ tokens
02 Tool Use The hands
  • Function calling to external APIs
  • Web browsing and data retrieval
  • Code execution in sandboxes
  • Database queries and writes
  • File system read and write access
  • MCP for standardised tool access
03 Planning & Reasoning The strategy
  • Chain-of-thought decomposition
  • Multi-step task planning
  • Self-reflection and error correction
  • Dynamic re-planning when blocked
  • Goal decomposition into subtasks
  • ReAct pattern: reason → act → observe
04 Memory & State The context
  • Short-term conversation memory
  • Long-term vector store retrieval
  • RAG for grounded responses
  • Session state across interactions
  • User preference learning
  • Knowledge graphs for relationships
05 Multi-Agent Orchestration The team
  • Specialised agents per task
  • Parallel execution of subtasks
  • Supervisor agent coordination
  • Shared context between agents
  • Human-in-the-loop approval gates
  • Autonomous end-to-end workflows
