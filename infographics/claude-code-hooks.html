Critical
Exit Codes
0
Allow
Action proceeds normally
1
Warn (does NOT block)
Stderr shown, execution continues
2
Block
Stops the action entirely

Security hooks must use exit 2. Exit 1 is the #1 mistake.

Stop hook infinite loop

When a Stop hook blocks (exit 2), Claude continues and fires Stop again forever. Always check stop_hook_active and exit 0 if true.
