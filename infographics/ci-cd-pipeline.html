The CI/CD Pipeline

From commit to production — every stage of modern software delivery.

1

Source

TRIGGER

Developer pushes code to the repository. A webhook triggers the pipeline. Branch protection rules gate what reaches main.

GitHub GitLab Bitbucket
2

Build

COMPILE

Source code is compiled, dependencies are resolved, and artifacts are produced. Container images are built and tagged.

Docker Gradle Webpack Turborepo
3

Test

VALIDATE

Automated test suites run: unit tests, integration tests, and end-to-end tests. Code coverage and quality gates must pass.

Jest Pytest Cypress SonarQube
4

Stage

PRE-PRODUCTION

Deploy to a staging environment that mirrors production. Run smoke tests, performance benchmarks, and security scans.

Terraform Helm k6
5

Deploy

PRODUCTION

Release to production using blue-green, canary, or rolling deployments. Feature flags control gradual rollout. Automated rollback on failure.

ArgoCD Kubernetes LaunchDarkly
6

Monitor

OBSERVE

Collect metrics, logs, and traces. Alert on anomalies. Feed insights back into the next iteration of development.

Datadog Grafana PagerDuty Sentry
