8 ChatGPT Prompt Frameworks
To Help You Master AI

1 R-T-F
R Role: Specify the persona or expert you want the AI to assume.
T Task: Define what the AI should produce — be specific about scope.
F Format: Set the output structure — bullets, table, essay, code, etc.
Example:
Role → Act as a brand strategist.
Task → Write a messaging hierarchy for a B2B SaaS founder targeting finance teams.
Format → Bullet points with core message, value props, proof, and CTAs.
2 S-O-L-V-E
S Situation: The context.
O Objective: The goals.
L Limitations: Constraints.
V Vision: End state.
E Execution: The steps.
Example:
Situation → Content team, new B2B startup.
Objective → Inbound leads via LinkedIn.
Limitations → No ads, small team, 3x/wk.
Vision → SaaS ops thought leader.
Execution → Biweekly review, optimize.
3 T-A-G
T Task: Define the specific task or challenge — include enough context.
A Action: State the concrete action or approach to address the task.
G Goal: Clarify the measurable target outcome and success criteria.
Example:
Task → Reduce customer churn in a SaaS subscription business.
Action → Analyse churn data and launch a targeted retention programme.
Goal → Improve customer retention rate by 15% over the next 6 months.
4 R-A-C-E
R Role: Character you want AI to play.
A Action: The instruction or job needed.
C Context: Provide the background info.
E Expectation: Describe the outcome.
Example:
Role → B2B go-to-market consultant.
Action → Build cold outreach framework.
Context → Workflow automation for logistics.
Expectation → 3 email templates per buyer role.
5 D-R-E-A-M
D Define: The problem.
R Research: The data.
E Execute: The plan.
A Analyse: The results.
M Measure: The outcomes.
Example:
Define → Declining B2B SaaS retention.
Research → User interviews + CRM data.
Execute → 3-month retention programme.
Analyse → Control vs. test cohorts.
Measure → Churn rate, usage, NPS.
6 P-A-C-T
P Problem: Define the problem.
A Approach: Describe the approach.
C Compromise: Potential trade-offs.
T Test: The test or measurement.
Example:
Problem → Low trial-to-paid conversion.
Approach → Redesign onboarding for value.
Compromise → Delay features for UX work.
Test → 6-week A/B on conversion.
7 C-A-R-E
C Context: Give the context.
A Action: Describe the action needed.
R Result: Clarify the expected result.
E Example: Provide an example for clarity.
Example:
Context → Low onboarding engagement.
Action → Redesign for quick wins.
Result → Higher adoption in 7 days.
Example → Day-7 activation: 25% → 42%.
8 R-I-S-E
R Role: Specify the role.
I Input: Describe the input needed.
S Steps: Could you ask for steps to follow?
E Expectation: Describe the expectation.
Example:
Role → Commercial director.
Input → Q1 sales data and pipeline forecasts.
Steps → Prioritise high-conversion leads.
Expectation → Plan to exceed Q2 revenue targets.
