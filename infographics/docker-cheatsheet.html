Docker Commands

The essential commands every developer needs — from containers to compose.

Container Lifecycle

docker run Create and start a new container from an image
docker start Start a stopped container
docker stop Gracefully stop a running container
docker restart Stop and restart a container
docker rm Remove a stopped container
docker kill Force stop a container immediately

Images

docker build Build an image from a Dockerfile
docker pull Download an image from a registry
docker push Upload an image to a registry
docker images List all locally stored images
docker rmi Remove one or more images
docker tag Tag an image for a registry

Inspection & Debugging

docker ps List running containers (-a for all)
docker logs View container stdout/stderr output
docker exec -it Open an interactive shell inside a container
docker inspect View detailed container/image metadata
docker stats Live resource usage (CPU, memory, I/O)
docker top Show running processes inside a container

Networking

docker network ls List all Docker networks
docker network create Create a custom network
docker network connect Attach a container to a network
docker port Show port mappings for a container
Use --network host for direct host networking (Linux only). Default bridge network isolates containers.

Volumes & Storage

docker volume create Create a named volume
docker volume ls List all volumes
docker cp Copy files between container and host
-v host:container Mount a host directory as a volume

Docker Compose

docker compose up Start all services defined in compose file
docker compose down Stop and remove all containers, networks
docker compose build Build or rebuild service images
docker compose logs View output from all services
Add -d flag to run in detached mode. Use --watch for live rebuild on file changes.
