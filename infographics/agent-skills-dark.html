What Are Agent Skills?

Standard operating procedures for AI. When you find yourself repeating a task — writing reports, reviewing code, following checklists — that's a perfect candidate for a skill. Write it once as a Markdown file, and your AI follows it automatically.

Skills work everywhere: Claude Desktop, Claude Code, Cowork, and coding agents like Cursor, OpenCode, and Codex. An open standard across 26+ platforms. Share with your team via git, or publish to skills.sh.

3
Execution

Inside a SKILL.md
YAML Header
Every skill starts with a name (kebab-case, max 64 chars) and a description that tells the agent what the skill does and when to activate it. This is all the agent reads at startup — just ~100 tokens.
Markdown Body
The core instructions. Write step-by-step workflows, include input/output examples, cover edge cases, and add troubleshooting guidance. Loaded only when the skill activates.
Supporting Files
Optional scripts (Python, Bash), reference docs, templates, and schemas. These load on demand during execution — never at startup.
