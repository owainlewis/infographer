Essential Git Commands

01
git commit

Snapshot your staged changes. Each commit is an immutable record in the project history. Write meaningful messages — your future self will thank you.

git commit -m "fix: auth redirect"
Core --amend to fix last
02
git branch

Create isolated lines of development. Branches are cheap pointers to commits. Use them for features, fixes, and experiments without touching main.

git switch -c feature/auth
Branching switch > checkout
03
git stash

Shelve uncommitted work. Stash saves your working directory and index state so you can switch branches cleanly, then reapply later.

git stash push -m "wip: sidebar"
Save WIP pop to restore
04
git rebase

Replay commits onto a new base. Creates a linear history by moving your branch to the tip of main. Interactive mode lets you squash, reorder, and edit commits.

git rebase -i main
Clean history -i for interactive
05
git cherry-pick

Apply a specific commit to your current branch. Grab exactly the changes you need without merging the whole branch. Essential for hotfixes and backports.

git cherry-pick a1b2c3d
Surgical Hotfixes
06
git bisect

Binary search through commits to find a bug. Mark commits as good or bad and git narrows the culprit in O(log n) steps. Automate it with a test script.

git bisect start HEAD v2.0
Debugging O(log n) search
07
git reflog

Your safety net. Records every HEAD movement locally — even after reset, rebase, or deleted branches. If you lost a commit, reflog knows where it went.

git reflog show --date=relative
Recovery Undo anything
08
git log

Explore project history. Filter by author, date, file, or message. The --oneline --graph combo gives you a visual branch map in your terminal.

git log --oneline --graph --all
History --author filter
09
git reset

Move HEAD and optionally rewrite the index. --soft keeps changes staged. --mixed unstages. --hard discards everything. Handle with care.

git reset --soft HEAD~1
Undo --hard is destructive
