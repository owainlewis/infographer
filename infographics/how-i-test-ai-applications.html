How I Test AI Applications

01
Unit Tests

Cheap, fast, run on every PR. Assert that classifications return valid categories. Check confidence scores are floats between 0 and 1. Verify response schemas match. These catch the obvious breaks in minutes.

pytest Fast Every PR
02
Tracing

Capture every request, response, and intermediate step. You cannot test what you cannot see. Find the most common queries. Find where things break. Without tracing you are guessing what to test.

Langfuse Foundation Day one
03
Golden Datasets

Build sample questions from your requirements. 10-20 per category. Does it handle warranty questions? Does it get pricing right? Does it know when to escalate? This defines what good looks like before you tune anything.

Requirements-driven Curated 10-20 per category
04
Human Evaluation

The step everyone skips. Have domain experts rate real outputs on defined criteria. Start binary: good or bad. Use a spreadsheet. This is your gold standard — everything else calibrates against it.

Gold standard Binary first Domain experts
05
LLM-as-Judge

Use a strong model to grade outputs at scale, but only after human eval. Run model and human critique on the same 100 pairs. Meta-prompt to optimize the judge. Repeat until >90% aligned.

Scalable Meta-prompting >90% agreement
